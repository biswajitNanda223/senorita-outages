API_Server -> etcd_DB: Read/Write cluster state
API_Server -> Scheduler: Watch unscheduled pods
API_Server -> Controller_Manager: Reconciliation loops
API_Server -> Kubelet_1: HTTPS PodSpecs
API_Server -> Kubelet_2: HTTPS PodSpecs

Kubelet_1 -> Runtime_1: CRI Start Container
Runtime_1 -> Pod_1: Run Fastify Pod

Kubelet_2 -> Runtime_2: CRI Start Container
Runtime_2 -> Pod_2: Run Fastify Pod
